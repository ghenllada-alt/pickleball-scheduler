🏓 Pickleball Live Court Scheduler

Courts operate independently. When a court finishes, the next fair match is assigned without using players who are still playing on another court.

1. Event Settings

The minimum-games setting is a fairness target only. Matches will continue after everyone reaches the target. The scheduler will stop creating matches only when you select End Event.

2. Players

Enter any number of players. Four available players are required to create a doubles match.
